# Spotify Clone 

A responsive and interactive Spotify Clone built using HTML, CSS, and JavaScript.  
This project is designed to provide a music streaming UI experience similar to Spotify with modern design and smooth user interaction.

##  Features

-  Play and pause music
-  Next and previous song controls
-  Dynamic song list
-  Music progress bar
-  Interactive music player UI
-  Responsive design for different screen sizes
-  Spotify-inspired modern interface

##  Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was created to improve frontend development skills and learn:
- DOM Manipulation
- Audio handling in JavaScript
- Responsive web design
- Interactive UI development

## Preview

Spotify Clone interface inspired by the original Spotify web player.

## Future Improvements

- Add volume controls
- Add playlist functionality
- Add dark/light theme
- Backend integration
- User authentication
